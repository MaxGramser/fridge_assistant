# 🖨️ Label Printer (DYMO + Zebra)

Prints **PNG/PDF** labels — and **raw ZPL** — on USB label printers via CUPS.
Several printers run side by side; each gets its own queue and callers pick one
by name. Built as the companion add-on to Fridge Assistant, but usable as a
generic label print service for anything (Label Assistant, a webshop, an
automation).

**Tested with a DYMO LabelWriter 400 + 99014 labels (54 × 101 mm) and a Zebra
ZD220D + 104 × 159 mm shipping labels, on one USB hub.**

See [DOCS.md](DOCS.md) for install, options and the HTTP API.
